You are a senior full-stack architect and AI systems engineer.

I am building a large-scale web application called "DSAstra".

PROJECT SUMMARY:
DSAstra is an AI-powered competitive programming platform designed to help users learn Data Structures & Algorithms (DSA), prepare for coding interviews and contests, and improve long-term retention using intelligent systems.

Unlike traditional platforms, this system focuses on:
• Personalized learning
• AI-guided recommendations
• Memory retention (Spaced Repetition)
• Performance analytics
• Real-time competitive features

--------------------------------------------------

CORE PROBLEM:
Most students:
• Solve problems randomly without structure
• Forget algorithms after a few days
• Don’t know their weak areas
• Lack feedback on code quality and approach
• Cannot simulate real interview or contest environments

--------------------------------------------------

SOLUTION:
DSAstra acts as a "Personal AI Coding Mentor" that:
• Recommends what to study
• Tracks weaknesses
• Reinforces memory using spaced repetition
• Analyzes code and complexity
• Simulates interviews and contests
• Predicts contest performance
