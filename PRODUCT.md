# Product

## Register

product

## Platform

web

## Users
College students and working professionals who are preparing for interviews, upskilling, and want to learn and practice Data Structures and Algorithms (DSA).

## Product Purpose
To provide a unified, advanced, yet simple platform to aggregate and solve DSA problems across multiple coding platforms (like LeetCode and CodeChef) in one place.

## Brand Personality
Simple, advanced, premium, soothing, and highly polished. It should feel like a state-of-the-art developer tool rather than a generic template.

## Anti-references
- "Cheap AI websites" with generic, over-saturated, or vibrant layouts.
- Punchy, irritating, or overly loud colors (avoid aggressive neon or high-contrast glare).
- Sloppy or boilerplate UI patterns that feel disconnected.

## Design Principles
1. **Focus Mode First:** The interface must prioritize the code editor and problem description above all else; zero distractions.
2. **Soothing Authority:** Use deep, calming dark themes with premium typography (like "Outfit") to reduce eye strain during long coding sessions.
3. **Professional Polish:** Every interaction, from running code to viewing logs, should feel deliberate, robust, and technically extraordinary.

## Accessibility & Inclusion
Ensure high legibility for long reading/coding sessions. Avoid rapid/jarring animations. Maintain accessible contrast ratios across the code editor and UI elements.
